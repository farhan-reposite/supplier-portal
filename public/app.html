Delivery schedule

Download the labels for a delivery date, print them, and stick one on each box.

How to print the labels on the POS-80 printer
  1. Fill in the No SJ (delivery note number) for that date. If you leave it empty, the label prints “Road Number”.
  2. Press Download labels. You get one PDF with one label per box (80 mm wide).
  3. Open the PDF in Chrome and press Ctrl+P. Choose the POS-80 printer.
  4. Set paper size to 80 mm × 80 mm (or the size set up in the printer), margins to None, and scale to 100% / Actual size.
  5. Print, then check that every label is complete and not smudged. You can download the same labels again at any time.
