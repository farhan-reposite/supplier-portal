How to print on the POS-80 printer
  1. Pick one or more dates in the calendar. Dates with deliveries show the number of boxes.
  2. Type the No SJ (delivery note number) for each date. If you leave it empty, the label prints “Road Number”.
  3. Press Print labels. The labels go straight to the POS-80 printer at the exact label size, with no print window. The first time on a computer you choose the printer; the Printer button changes it later.
  4. This needs the QZ Tray app running on the computer that has the printer. If it is not running, you are offered the normal browser print window instead (the label size may not match).
  5. Prefer a file? Download PDF gives the same labels, one per page.
  6. A label damaged? Select the date again, untick other parts, set the box range (for example 3 to 3), and print just that label.
